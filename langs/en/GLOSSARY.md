# English glossary

The English terms of the franchise come from the official localisation of
*Medabots* (the anime and the Game Boy Advance games). Use them; do not invent new
ones, and do not romanise a term that already has an English name.

## Franchise terms

| English term | Note |
|---|---|
| **Medabot / Medabots** | The robots. Never "robot" on its own. |
| **Medafighter** | A person who fights with Medabots. |
| **Robattle** | The fight itself, and the verb: "to Robattle". |
| **Submission Robattle** | The stakes match: the loser hands a part to the winner. |
| **Medaforce** | The special attack. |
| **Medachange** | Transformation. Not "Medachange" translated, it is the name. |
| **Medapart** | A part: head, arms, legs. Plural "Medaparts"; "part" alone is fine in tight UI. |
| **Medal** | The Medal that gives a Medabot its will. |
| **Tinpet** | The skeleton a Medal and parts are mounted on. Untranslated. |
| **Medawatch** | The wrist device. |
| **Rubberobo Gang** | The villains. |
| **Metabee** | Model KBT01. Unchanged. |
| **Rokusho** | Model KWG01. Unchanged. |
| **Referee** | The Referee (Mr. Referee in the anime). |
| **Function ceased!** | The Referee's ruling when a Medabot is defeated. |
| **Kabuto / Kuwagata Ver.** | The two releases. Release names are not translated. |

## Card game terms

The game is a TCG, so use standard trading-card wording: *deck*, *hand*, *draw*,
*discard pile*, *cost*, *turn*, *pack* (not "envelope"), *mulligan*.

| English term | Note |
|---|---|
| **Leader** | The main Medabot. |
| **Barrier** | The shield mechanic. "Barrier Hand" is the mechanic of playing barrier cards from hand. |
| **Discard pile** | Where destroyed cards go; "Discard" alone in tight UI. |
| **Quick cooldown** | Puts a Medabot on standby immediately. |
| **Standby** | The state a cooled-down Medabot is in. |
| **Overheat** | The state after acting. |
| **Action phase / Draw phase / Preparation phase / End phase** | Phase names. |
| **Charge** | The stat. Keep it distinct from **Boost** (the keyword) and **Propulsion** (movement). |
| **Support** | The card type. Keep it distinct from **Cheer**. |
| **Transfer / Re-transfer** | Putting a Medabot into play / replacing one already in play. |
| **Banish** | Removing from play without going to the discard pile. |
| **Threshold: X** | Triggers at power ≥ X. |
| **Revive: X** | Brings a copy back from the discard pile, overheated. |
| **Finisher** | Extra damage equal to your own power. |
| **Original Bonus** | Bonus for equipping a part on its own Medabot. |
| **Substitute** | Destroyed in the leader's place. |

## Status effects and keywords

Capitalise them as rule names: **Burn**, **Bind**, **Shock**, **Freeze**, **Frenzy**,
**Deathlock**, **Confusion**, **Guard**, **Super Guard**, **Absolute Guard**,
**Snipe**, **Cross Attack**, **All-Terrain**, **Untargetable**.

Leg types: **Biped**, **Multi-leg**, **Vehicle**, **Flight**, **Submarine**,
**Tank**, **Hover**, **Omni**.

## Style rules

1. **Space is tight.** This is a card-game UI on a handheld. Always pick the
   shortest wording that keeps the meaning. English is usually shorter than the
   Japanese, but not always — watch card names and button labels.
2. **Sentence case** for descriptions; **Title Case** for card, part and keyword
   names.
3. **Keep the markers.** Placeholders `{0}`, `{1}`, line breaks `\n` and tags such
   as `<color=#FF3174>` or `<size=-5>` are copied over exactly. Numbers (2000,
   3000, 10000) and the parametric `X` stay as they are.
4. **Full-width brackets** `【…】` become `[ ]`; translate what is inside them.
5. **Do not translate what the game already shows in English** (`New`,
   `New Record`, `MAX`).
6. **Do not translate names of real people**: `StaffCredits` and
   `SupecialSupporter` are the game's staff and its crowdfunding backers.
7. **Proper names** are romanised, not translated: Saito, Tsukiji, Memochi, Amu,
   Nei, Marina, Manabu, Hakuga, Uruchi. Titles are translated ("Card Director").
8. **Report original bugs, do not imitate them.** Three entries in the buff table
   are broken in the game itself: one carries the wrong text, two have none.
